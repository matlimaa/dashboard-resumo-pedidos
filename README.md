# 📋 Resumo de Pedidos

Userscript para facilitar a visualização e conferência de pedidos.

O script captura as principais informações do pedido aberto e gera um resumo organizado, facilitando a conferência e o envio das informações ao cliente para confirmação.

## ✨ Funcionalidades

O resumo apresenta:

* 🚚 Tipo do pedido — Delivery ou Retirada
* 🍕 Produtos do pedido
* ➕ Adicionais e opções selecionadas
* 📝 Observações
* 💵 Valor dos itens
* 🚚 Taxa de entrega
* 💰 Valor total

## 🎯 Objetivo

Transformar as informações do pedido em uma visualização mais simples e organizada, facilitando a conferência antes da confirmação com o cliente.

## ⚙️ Funcionamento

Após instalar o script através do **Tampermonkey**, um botão flutuante é adicionado à página.

Ao clicar nele, o pedido atualmente aberto é analisado e suas principais informações são apresentadas em um resumo.

## 🛠️ Tecnologias

* JavaScript
* DOM API
* MutationObserver
* Tampermonkey

Não possui dependências externas.
